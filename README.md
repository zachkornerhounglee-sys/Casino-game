# RNGdle: Totally Normal Casino

A static browser game packaged for GitHub Pages.

## Run locally

Open `index.html` in a modern browser. An internet connection is needed because the page loads Three.js, PeerJS, and the Inter font from CDNs.

## Publish with GitHub Pages

1. Create or open a GitHub repository.
2. Upload the **contents** of this folder (especially `index.html`) into the repository's root. Do not upload only the ZIP and expect GitHub Pages to unpack it.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, then select branch `main` and folder `/(root)`, and save.
6. Wait for GitHub Pages to finish deploying, then open the Pages URL shown in Settings → Pages.

The game is a static site and does not require a build step.
